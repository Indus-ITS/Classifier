# Repo cleanup

Date: 2026-05-13
Status: Draft

## Goal

Strip the codebase to only what the new pipeline (`classify`,
`convert-classified`, `build-type-enum`) needs. Remove the legacy
`sort-files` machinery, the legacy diagnostic tools, and the dead modules
that survived earlier refactors. Result: ~15 Python files under
`src/classifier/`, three CLI entry points, no dangling imports.

## Why

- The new pipeline does one thing well (fill `doc_type` and `type` in a
  canonical CSV). Most of the inherited codebase served the old
  xls-walking, file-sorting workflow and is not needed.
- Dead code rots: easier to forget which path is canonical, harder to
  reason about which modules to touch when improving the classifier next.
- Smaller surface area means the classifier-improvement workstream can
  focus on `core/scoring.py` and friends without wading through unused
  files.

## Out of scope

- No behavior changes to the surviving code.
- No classifier improvements (next workstream).
- No additions to the pipeline.
- No tests (per standing user direction).

## Verification

**Step 0: capture baseline hashes BEFORE any deletion** so the byte-identical check at the end has something to compare against:

```bash
.venv/Scripts/python -c "
import hashlib, pathlib, json
def hash_tree(root):
    h = hashlib.sha256()
    for p in sorted(pathlib.Path(root).rglob('*'), key=lambda x: str(x).lower()):
        if p.is_file(): h.update(p.read_bytes())
    return h.hexdigest()
baseline = {
    'classified_csv': hash_tree('input/classified_csv'),
    'output_classified_csv': hashlib.sha256(pathlib.Path('output/classified.csv').read_bytes()).hexdigest(),
}
pathlib.Path('.baseline-hashes.json').write_text(json.dumps(baseline, indent=2))
print(baseline)
"
```

Then proceed with deletions / edits.

Final byte-identical check against the baseline captured in Step 0:

```bash
.venv/Scripts/python -c "
import hashlib, pathlib, json
def hash_tree(root):
    h = hashlib.sha256()
    for p in sorted(pathlib.Path(root).rglob('*'), key=lambda x: str(x).lower()):
        if p.is_file(): h.update(p.read_bytes())
    return h.hexdigest()
baseline = json.loads(pathlib.Path('.baseline-hashes.json').read_text())

    'classified_csv': hash_tree('input/classified_csv'),
    'output_classified_csv': hashlib.sha256(pathlib.Path('output/classified.csv').read_bytes()).hexdigest(),

pathlib.Path('.baseline-hashes.json').unlink()
```
